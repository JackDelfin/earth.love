#-------------------------------------------------------------------------------
# Token Manipulation Functions
#-------------------------------------------------------------------------------
#ASSIGN        [value].[backup(1/0) or BackupExt]# - Token Assignment without parsing (also #token=[value]# without function name); Backup (1) will set existing value of TOKEN to TOKEN_BACK as default, or BackupExt could be set instead (ie _BACKUP).
#PARSE         [text]#            - Parses the text, replacing tokens and functions, including modifiers
#ONEPARSE      - Same as PARSE, but only parses the text once
#GETTOKEN      [TokenName] - Gets the contents of the token without parsing; To get a Token Reference value, include # around token name (ie #tokRefVal=GetToken[#tokRef#]#
#LOADMOD       [OML_Function_Module] - Load the Function Group Module (Number or Name) for additional function support - see USERMOD21 through USERMOD27;  ALL may be specified to load all Function Groups.  Note this happens automatically for standard OML functions.
#LOADTOKEN     [tok=value\n ...]# - Load a list of tokens, carriage return separated, and token specified as: token = [ value ] token = value token=value - No parsing is done; one token per line
#TOKENLOAD     - Same as LOADTOKEN
#LOADMSG       [tok=value\n ...]# - Same as LOADTOKEN, but also performs a MSG translation for each value
#MSGLOAD       - Same as LOADMSG
#BACKUP        [token]...[token]# - Backup all of the TOKENs, setting existing value to TOKEN_BACK (default).  #BackupExt[_BAK]# provides an alternate Extension.
#RESTORE       [token]...[token]# - Restore all of the token values to TOKEN_BACK. Only uses default Backup Extension

#-------------------------------------------------------------------------------
# Message and Language Functions
#-------------------------------------------------------------------------------
#MESSAGE       [MessageCode].[MessageText].[HelpText].[CommentText]# - Returns the translated message text for the MessageCode specified, optionally setting the MessageText, Help, and Comment Text.
#MSG           - Same as MESSAGE
#MSGLIST       [MessageCode].[MessageList].[HelpText].[CommentText]# - MessageList is a separated list (\n|;:) of items, (i.e. a list of weekdays for a Select list).  Returns the translated message text for the MessageCode specified in the default Language.  Optionally set the Help and Comment Text.
#MSGHELP       [MessageCode].[HelpText]# - Returns the help text for a MessageCode

#LANGUAGE      [LangCode].[MessageCode]...[MessageCode]# - Change the Language to the LangCode specified and set Tokens for the optional MessageCode(s), translated, with MSG_ prefix (i.e. #MSG_SEARCH#).
#LANG          - Same as LANGUAGE
#SETLANG       - Same as LANGUAGE

#-------------------------------------------------------------------------------
# OML Template and Data Include Functions
#-------------------------------------------------------------------------------
#INCLUDE       [TEMPLATE].[_1_].[_2_].[_3_]...[_n_]# - Include an OML Template file, and optionally set token parameters #_1_# #_2_# ...
#INC           - Same as INCLUDE
#OML           - Same as INC - Create your own OML function
#FUNCTION      - Same as OML

#IFINCLUDE     [condition][then template].[else template]#   - if the expression is true, include "then template", or else include "else template"
#INCLUDEIF     - Same as IFINCLUDE
#INCIF IFINC   - Same as IFINCLUDE
#OMLIF IFOML   - Same as IFINCLUDE

#BEFORE       [YYYYMMDDHHMISS].[then template].[else template].[_1_].[_2_].[_3_]...[_n_] - Continues processing and optionally loads additional templates if current date is BEFORE the partial date specified (date could be a token). False is the same as STOP.
#AFTER        [YYYYMMDDHHMISS].[then template].[else template].[_1_].[_2_].[_3_]...[_n_] - Continues processing and optionally loads additional templates if current date is AFTER the partial date specified (date could be a token). False is the same as STOP.
#SHOWON       [YYYYMMDDHHMISS].[then template].[else template].[_1_].[_2_].[_3_]...[_n_] - Continues processing and optionally loads additional templates if current date is the partial date specified (date could be a token). False is the same as STOP.
#STOP         [condition]# - Stops processing of the current INCLUDE template if condition is TRUE (1)

#-------------------------------------------------------------------------------
# Conditional Functions
#-------------------------------------------------------------------------------
#IF            [condition][then].[else]# - traditional if statement, shows then or else
#EVAL          [condition].[then].[else]#   - evaluates the boolean expression and returns boolean 1 or 0; null evaluates to 0;  Optional Then and Else act like an IF
#AND           [eval].[eval]...[eval]#   - returns 1 if ALL evals are true, 0 otherwise
#OR            [eval].[eval]...[eval]#   - returns 1 if ANY of evals are true, 0 otherwise
#EQUAL         [val1][val2].[then].[else]# - tests for equality, returning 1/0 or then/else.  2 calling modes
#NOTEQUAL      - Opposite of EQUAL
#NVL           [val1][val2]...[valn]# - Returns the first non null (blank) argument
#DECODE        [condition][if].[then]...[if][then]...[else]# - Like a case statement
#DECODELIKE    - DECODE with wildcard expressions in the "if", using *% or _.?
#CASE          - Same as DECODELIKE, with built-in pattern matching
#EXISTS        [text].[then].[else]# - conditionally show then/else if text is null
#ISNOTNULL     - Same as EXISTS
#NOTNULL       - Same as EXISTS
#NOTEXISTS     [text].[then].[else]# - conditionally show then/else if text is NOT null
#ISNULL        - Same as NOTEXISTS
#NULL          - Same as NOTEXISTS
#LIKE          [val1][val2].[then].[else]# - Text wildcard expression (*% _.?) for equality, returning 1/0 or then/else.  2 calling modes
#ILIKE         - Same as LIKE, but case insensitive
#IN            [text][in1][in2]...[inx]# - Checks for text in the specified arguments
#INLIKE        - Same as IN, but with wildcard expression (*% _.?) 
#NOTIN         - Same as IN, but inverse
#NOTINLIKE     - Same as INLIKE, but inverse


#-------------------------------------------------------------------------------
# Numeric Conditional Functions (like a quick IF statement)
#-------------------------------------------------------------------------------
#GT            [val1][val2].[then].[else]# - Returns 1/0 if val1 is GREATER THANval2 (text and numbers) or returns then/else if specified.  2 calling modes
#GREATERTHAN   - Same as GT
#LT            [val1][val2].[then].[else]# - Returns 1/0 if val1 is LESS THAN val2 (text and numbers) or returns then/else if specified.  2 calling modes
#LESSTHAN      - Same as LT
#GE            - Same as GT, but greater than or equal
#GREATEREQUAL  - Same as GE
#LE            - Same as LT, but less than or equal
#LESSEQUAL     - Same as LE
#BETWEEN       [text/num][low][high].[then].[else]# - Returns 0/1 if text/num is between low and high.  Returns then/else if specified.  2 calling modes


#-------------------------------------------------------------------------------
# String Functions
#-------------------------------------------------------------------------------
#REPLACE       [text][find].[replace] - Replace [find] in [text] with [replace].  Replace First occurance only.
#REPLACEALL    [text][find].[replace] - Replace [find] in [text] with [replace].  Replace ALL occurances with Regular Expressions
#IREPLACE      - Case insensitive REPLACE with Regular Expressions
#IREPLACEALL   - Case insensitive REPLACEALL with Regular Expressions
#FORMAT        - 2 Formats: [date].[in_format].[out_format]#   [number].[format]#   - Formats the date/number to the specification given, or system default
#NUMFORMAT     [Thousands_Sep][Decimal_Sep][Currency_Symbol]# - Set the Thousands, Decimal, Currency formats for use in FORMAT
#SUBSTR        [text][start].[length]#  - Gets a substring from [text] beginning at [start] and getting [length] chars.  1-based substr (Oracle) - returns 0 if not found
#SUBSTR0       - Same as SUBSTR, but 0-based (Perl) - returns -1 if not found, 0 for beginning of string
#INSTR         [text][find].[begin]#   - Position of [find] in [text], starting at [begin]. 1-based offset, returns 0 if string not found, similar to Oracle "instr"
#INDEX         [text][find].[begin]#   - Position of [find] in [text], starting at [begin]. 0-based offset, returns -1 if string not found, similar to Perl "index"
#TRANSLATE     [text][from][to]#       - Translates the characters in [from] to the characters in [to].
#RPAD          [text][length].[char]#  - Right pad text with char up to length
#LPAD          [text][length].[char]#  - Left pad text with char up to length
#RTRIM         [text][char]#           - Right Trim char from text
#LTRIM         [text][char]#           - Left Trim char from text
#TRIM          [text][char]#           - Right AND Left Trim char from text
#APPEND        [text1].[text2].[linebreak]#   - Appends text2 to text1, with optional likebreak; returns appended string


#-------------------------------------------------------------------------------
# Wrap and Text Formatting
#-------------------------------------------------------------------------------
#ROWS          [text].[max_linelength].[min_rows].[max_rows]#                    - Returns number of rows or lines of text based on the max linesize, limiting by min_rows and max_rows
#WRAP          [text].[max_linelength].[wordbreak_chars].[linebreak_chars]#      - Wrap the text based on max linelength, and optionally wordbreak or linebreak characters
#WRAPTOKEN     [tokenName].[max_linelength].[wordbreak_chars].[linebreak_chars]# - Same as WRAP, but directed to the specified tokenName
#STRIPTEXT     [text][begin_text][end_text].[replace_text].[match_pairs]#        - Replace Text based on begin/end tags (<!--- --->), replacing with replace_text if specified, and matching pairs 0/1


#-------------------------------------------------------------------------------
# Math and Number Related Functions
#-------------------------------------------------------------------------------
#ROUND         [num].[decimals:0-4]#  - Rounds a number to decimals specified
#TRUNC         [num].[decimals:0-4]#  - Truncates a number to decimals specified
#SIGN          [num]#                 - Returns -1/0/1/null if num is negative, zero, positive, or null if not a number
#ABS           [num]#                 - Returns absolute value of a number (positive)
#MOD           [num][divisor]#        - Returns the modulus (remainder) after a division
#ADD           [num].[num]...[num]#   - Adds all the numbers in the list
#SUB           [num].[num]...[num]#   - Subtracts all the numbers in the list from the first num
#SUBTRACT      - Same as SUB
#MULT          [num].[num]...[num]#   - Multiplies all the numbers in the list
#MULTIPLY      - Same as MULT
#DIV           [num].[num]...[num]#   - Divides all the numbers in the list from the first num
#DIVIDE        - Same as DIV
#MIN           [a].[b]...[n]#         - Returns the minimum (String/Numeric) from the list
#MAX           [a].[b]...[n]#         - Returns the maximum (String/Numeric) from the list
#AVG           [a].[b]...[n]#         - Returns the average of all numbers in the list
#RAND          [num][offset][seed]    - Returns a random integer number between 1 and the number specified;
               - num=0 will return a floating point decimal < 1 (i.e. 0.1234567);
               - offset (default 1) - specify 0 for a 0 based offset (0 to num-1) (ex. #RAND[10][][0]# returns 0-9)
                        - offset can also be used to return an random number at a higher range
                          (ex. #RAND[1000][][10000]# - returns 10000 to 10999)
               - seed - provides a starting seed number (integer) for the random generator;
#RANDOM        - Same as RAND
#DISTANCE      [lat,long][lat,long][km]#  - Returns Distance in miles between 2 Geo coordinates; km=1 for kilometers
#BEARING       [lat,long][lat,long][dir]# - Returns Bearing from first Geo coordinate to second (360 degrees North heading); dir=1 for directional N S E W
#FIBONACCI     [start_iteration][end_iteration][delim]# - Returns the Fibonacci sequence starting and ending at specified iterations, delimited by delim (def ,)

#-------------------------------------------------------------------------------
#
# TOKEN MODIFIERS within OML (Orbit Markup Language)
#
#-------------------------------------------------------------------------------

#-------------------------------------------------------------------------------
# String Modifiers
#-------------------------------------------------------------------------------
  .trim         - Trims the left and right \t \n <space>
  .ltrim        - Left Trim \t \n <space>
  .rtrim        - Right Trim \t \n <space>
  .space        - Replace multiple spaces with single space
  .length       - Returns length of Token value
  .upper        - Uppercase the Token value
  .lower        - Lowercase the Token value
  .initcap      - Initial Capitalize
  .initname     - Initial Capitalize with proper Name rules
  .namecap      - Same as .initname

#-------------------------------------------------------------------------------
# Existence Modifiers used for Boolean Conditions
#-------------------------------------------------------------------------------
  .0            - Returns '0' if Token is null or blank
  .1            - Returns '1' if Token is null
  .not          - Returns the inverse of the Boolean value 0/1
  .isnumber     - Returns '1' if the  Token value is a Number
  .exists       - Returns '1' if the Token value exists (IS NOT NULL), '0' otherwise
  .isnotnull    - Same as .exists
  .notexists    - Returns '1' if the Token value does NOT exist (IS NULL), '0' otherwise
  .isnull       - Same as .notexists
  .null         - Returns 'NULL' if Token is null or blank
  .eval         - Evaluates and parses the Token value contents, returning boolean 0/1

#-------------------------------------------------------------------------------
# Text Area Modifiers
#-------------------------------------------------------------------------------
  .rows         - Returns the number of rows (carriage returns, \n) in the data
  .cols         - Returns the max column length of all the lines

#-------------------------------------------------------------------------------
# HTML Modifiers
#-------------------------------------------------------------------------------
  .html         - escape any HTML text for display
  .raw          - Same as .html (older convention in Oracle)
  .nbsp         - Returns '&nbsp;' if the Token value is null
  .tr           - Translate special HTML characters for Form Gets
  .checked      - Returns 'CHECKED' if the boolean is 1 (true)
  .checkbox     - Returns the Token value of CHECK_ON or CHECK_OFF based on boolean evaluation
  .notags       - Replaces < with &lt; and > with &gt; and & with &amp;
  .noparse      - Replace # with &#035;, essentially showing Orbit Tokens unparsed
  .noquote      - Replace " with &quot;
  .untag        - Replace (&amp; &lt; &gt;) with (& < >)
  .unparse      - Replace &#035; with #
  .unraw        - Replace (&amp; &lt; &gt; &#035; &quot;) with (& < > # ")
  .nohtml       - Removes all HTML tags from the text
  .jsquote      - Escapes JavaScript code, such as double quote
  .br           - Changes all \n Carriage Returns to html <br>
  .nowrap       - Changes all spaces to &nbsp;

#-------------------------------------------------------------------------------
# Numeric Modifiers
#-------------------------------------------------------------------------------
  .sign         - Returns -1 for negative numbers, 1 for positive, 0, or null
  .round        - Rounds the number to closest integer
  .round2       - Rounds to 2 decimal places (useful for currency), pads with 0
  .round1       - Rounds to 1 decimal place, pads with 0
  .trunc        - Truncates the number, returning integer
  .abs          - Absolute Value (converts negative to positive)
  .ceil         - Ceiling of the number
  .floor        - Floor of the number
  .percent      - Shows the number in percentage format, multiplying by 100 and adding %
  .percent1     - Shows percent with 1 decimal places, padding with 0
  .percent2     - Shows percent with 2 decimal places, padding with 0

#-------------------------------------------------------------------------------
# Custom Token Functions
#-------------------------------------------------------------------------------
  .oml<token>   - OML User Defined Modifier, prefixed with OML. Shows the token named #OML<token># (defined prior to use). Reference token value internally as #OML#
                - ie #OMLRED=[<font color="red">#OML#</font>]#   #tok.OMLRed#

#-------------------------------------------------------------------------------
# Token Action functions - affects token table
#-------------------------------------------------------------------------------
  .backup       - Backup the TOKEN, setting existing value to TOKEN_BACK as default.  This is processed before other modifiers
  .restore      - Restore the Backup value TOKEN_BACK to the TOKEN name, keeping the backup token.  This is processed after .backup before any other modifiers.

#-------------------------------------------------------------------------------
# Caching Modifiers
#-------------------------------------------------------------------------------
  .cache        - Sets the Token cache flag so it will not be parsed further - returns Token value
  .uncache      - Unsets the Token cache flag - returns Token value
