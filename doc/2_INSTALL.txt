------------------------------
4.1 Run the INSTALL_earthlove.pl script
------------------------------

perl INSTALL_earthlove.pl

NOTE: Run the script to show user configurable parameters

------------------------------
4.2 Configure Apache:
------------------------------

1. Edit the httpd.conf Web Server Configuration file
   in Apache.

EDIT FILE: <APACHE>/conf/httpd.conf

2. Search for ServerAdmin in Apache httpd.conf.

CHANGE:
# Community Admin for this earth.love server
ServerAdmin COMMUNITY_ADMIN@earth.love

COMMUNITY_ADMIN is the specific email setup for the
community Server.

If you need a COMMUNITY_ADMIN email at @earth.love,
please see:
  http://COMMUNITIES.earth
  eco://Communities

3. Include Virtual Hosts in Apache httpd.conf.

CHANGE:

# Virtual hosts
# Include conf/extra/httpd-vhosts.conf

TO:

# Virtual hosts
Include conf/extra/httpd-vhosts.conf

4. Edit the Virtual Hosts file in Apache.

EDIT FILE: <APACHE>/conf/extra/httpd-vhosts.conf

5. ADD Virtual Hosts lines from:

  DEVELOPMENT_VIRTUAL_HOSTS.txt

to the httpd_vhosts.conf file.

!!!Edit appropriately for your configuration!!!

6. DIRECTORY: <APACHE>/htdocs

ADD YOUR COMMUNITY STATIC PAGE FILE: index.html

INDEX.HTML - earth.love version comes as default
             if you wish

7. DIRECTORY: <APACHE>/cgi-bin

Confirm earth.love installation files are present:

  akashic.pl
  eagle.pl
  orbit.pl


--------------------------------------------------
5. Configure your local hosts
--------------------------------------------------
Local hosts:
  /etc/hosts
  c:/windows/system32/drivers/etc/hosts

Output from UNITY will give instructions
and DATA to COPY-PASTE.


--------------------------------------------------
6. Restart Apache
--------------------------------------------------

httpd -k restart


--------------------------------------------------
7. Point your WEB browser to MY.earth.love
--------------------------------------------------

http://MY.earth.love
