ENVIRONMENT
------------------------------------------

Choose where to install the earth.love "ROOT".

An "Envoronment e/Variable" named EARTH_LOVE
can define this within your operating system.

earth.love can be installed on Windows and
Unix based systems for personal development
of the MY feature.

We will work collaboratively to support
the akashic data structure and library
on other platforms if needed.
